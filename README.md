# cafetec-legal

Repositorio con los documentos legales de Cafetec: Términos y Condiciones y Aviso de Privacidad.

- Página pública: https://brayanrcs.github.io/cafetec-legal/
- Documento PDF con los Términos y Aviso de Privacidad: `cafetec_terminos_aviso_privacidad.pdf`

Última actualización: 2 de mayo de 2026

Instrucciones rápidas:
1. Para actualizar la página, editar `index.html`.
2. Para reemplazar el PDF, subir `cafetec_terminos_aviso_privacidad.pdf` a la raíz del repositorio.
